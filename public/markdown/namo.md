# Namo (나모)

원하는 식물을 원격으로 기르고 실물로 배송받는 원격 식물 재배·배송 서비스

- **기간**: 2026년 ~ 진행 중
- **팀**: 2인
- **역할**: 초기 앱 구현 → 현재 하드웨어(펌웨어) 담당
- **펌웨어 저장소**: [namo-labs/namo-firmware](https://github.com/namo-labs/namo-firmware)

## 프로젝트 개요

Namo는 사용자가 고른 식물을 원격 환경에서 재배하고, 자라는 과정을 앱에서 확인하며 돌본 뒤 실물로 받아볼 수 있는 서비스입니다. 현재는 파일럿 단계로, 실제 장비로 **바질을 원격 재배**하고 있습니다.

## 담당 업무

### 1. 앱 구현 (초기)

- **Lynx(ReactLynx)** 로 앱을 구현했습니다.

### 2. 하드웨어 · 펌웨어 (현재)

**ESP32-S3** 펌웨어를 **Rust**(`esp-idf-svc`, `esp32-nimble`)로 작성하고 있습니다.

- **BLE**로 화분의 토양 센서 값을 읽기
- 물통 수위를 감시해 물이 없으면 급수 거부
- **MOSFET**으로 수중 펌프를 구동해 급수
- 상태 보고와 급수 명령은 MQTT로 주고받기

## 설계 원칙 — 안전 판정은 장치 안에서

급수 가능 여부와 중단 조건 같은 **안전 판정은 서버 연결과 무관하게 장치 안에서 끝나도록** 설계했습니다. 네트워크나 서버가 끊긴 상태에서도 펌프가 멈추지 않고 도는 상황이 생기지 않도록 하기 위해서입니다.

판정 로직은 하드웨어에 의존하지 않는 별도 크레이트로 분리해, 실제로 물을 뿌리기 전에 호스트 환경에서 테스트로 먼저 검증할 수 있게 했습니다.

## 기술 스택

- **펌웨어**: Rust (std, ESP-IDF) · `esp-idf-svc` · `esp32-nimble`
- **보드**: ESP32-S3
- **통신**: BLE, MQTT
- **앱(초기)**: Lynx (ReactLynx)
