# (주)오파크 — 풀스택 개발자

- **기간**: 2026년 1월 ~ 2026년 8월 (퇴사)
- **소속**: (주)오파크
- **역할**: 풀스택 개발자

## 회사 / 제품 소개

(주)오파크는 건축·인테리어 산업의 자재 거래를 디지털로 연결하는 스타트업입니다. 두 개의 주력 서비스를 운영하고 있습니다.

- **[TOONT-M](https://toont-m.com)** — AI 기반 건축 자재 매칭 플랫폼 (B2B SaaS)
  - 이미지/텍스트 기반 자재 검색
  - 건축·인테리어 전문가 ↔ 자재 공급사 매칭
  - 발주·배송·시공까지 아우르는 프로젝트 관리
- **TOONT** — 자사몰 (toont.co.kr)

## 담당 업무

### 1. TOONT-M 플랫폼 개발

사내 핵심 SaaS인 TOONT-M의 **Buyer·Partner·Admin 3개 서비스를 전담해 구현**했습니다.

- 프론트엔드 / 백엔드 / 데이터 모델링까지 도메인 단위로 책임지고 구현
- 자재 검색 RAG 서비스 고도화 및 플랫폼 연동 작업
- 건축자재 시장을 수용하는 커머스 플랫폼 구축
- PostgreSQL을 단일 원천(SSOT)으로 두고 **RLS로 앱별 권한을 분리**, local → staging → production 마이그레이션 파이프라인 구성
- BigQuery와 Cloud SQL 사이에 뷰를 두어 두 저장소 간의 인터페이스 계약으로 사용
- 플랫폼 결제와 정산지급대행을 **Payple**로 연동

### 2. SMS ↔ Slack 게이트웨이 구축

CS 운영팀이 사용하던 **CS폰의 SMS 송·수신을 Slack에서 처리할 수 있도록** 자체 게이트웨이 서비스를 설계하고 구축했습니다.

- CS폰으로 들어오는 SMS를 실시간으로 Slack 채널에 전달
- Slack에서 답장 메시지를 작성하면 CS폰 번호로 SMS 발신
- CS 응대 이력의 추적 가능성 / 다인 협업 / 부재 대응을 한 번에 해결
- 기존 휴대폰 한 대에 묶여 있던 CS 워크플로우를 팀 단위로 확장

### 3. TOONT 쇼핑몰 리뉴얼

자사몰 [toont.co.kr](https://toont.co.kr)의 리뉴얼 프로젝트 전반을 담당했습니다.

- 사이트 구조·디자인·기능 리뉴얼 전반 책임
- **결제 시스템 관리** — 포트원·네이버페이 연동, 결제 플로우 점검, 운영 이슈 대응
- **Meta Pixel 관리** — 이벤트 설계, 전환 추적, 광고 성과 측정 인프라 구성
- 마케팅 / 운영 부서 요구사항 반영 및 데이터 연동

### 4. 3D Configurator 구축 및 플랫폼 적용

**팀원과 함께** WebGL(Three.js) 기반 3D Configurator 엔진을 개발하고, 자사몰과 플랫폼 상품에 적용했습니다.

- 상품 옵션에 따라 형태·소재·마감을 실시간으로 커스터마이징하는 기능 구현
- 엔진을 Artifact Registry의 사내 Private 패키지로 배포해 자사몰과 B2B 플랫폼이 같은 구성기를 사용하도록 구성
- 자사몰 제품 Configurator 운영: [맞춤형 가구 플라스터월](https://toont.co.kr/products/custom-furniture-plaster-wall/configure)
- 다수 공급사 제품의 플랫폼 입점에 3D Configurator 적용
- AI 생성 텍스처와 코드 기반 모델링을 활용해 신규 제품군의 라인업 구성 속도 향상

### 5. 클라우드 운영 및 배포 자동화

- Cloud Run 서비스 10개 이상과 Cloud SQL, Cloud Scheduler를 production / staging 환경으로 나눠 운영
- PR 라벨 기반 **PR Preview** 구축 — GitHub Actions + Workload Identity + Cloud Build로 배포하고 IAP로 접근 보호

### 6. 에이전트 개발 환경 구축

- 레포별 CLAUDE.md, 에이전트용 검증 스크립트, 워크트리 격리 규칙 등을 정비해 코딩 에이전트가 같은 기준으로 작업하고 검증할 수 있는 개발 환경 구성

## 사용 기술 / 일하는 방식

- **개발 스택**: **Next.js 기반 풀스택 개발** (프론트·API 라우트·서버 사이드 로직 통합)
- **인프라**: **GCP(Google Cloud Platform)** 전반 활용 — 서버, DB, Cron 등 구글 계열로 통일 (스타트업 크레딧 활용)
- **근무 형태**: 대면 / 재택 **하이브리드**로 근무
- **운영 모니터링**: 에러 / 특정 이벤트 발생 시 **슬랙봇이 알림을 발사**하도록 직접 구축, 슬랙 채널 단일 창구로 운영 상황 파악
