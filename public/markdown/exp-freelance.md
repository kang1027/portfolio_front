# 개인사업자 · 프리랜서

- **기간**: 2025년 7월 ~ 현재
- **형태**: 개인사업자
- **역할**: 외주 개발 / 자체 제품 개발

## 개요

개인사업자로 등록해 외주 개발을 진행하면서, 직접 기획한 자체 제품을 함께 개발하고 운영하고 있습니다.

## 주요 업무

### 외주 개발

- 클라이언트의 요구사항을 받아 서비스를 설계하고 구현

### 자체 제품 개발

- **[OmniNews](https://github.com/Omni-News)** — 뉴스와 RSS를 한 곳에서 구독·검색하는 정보 구독 서비스
- **[ClassicMap](https://github.com/ClassicMap)** — 클래식 음악 입문자를 위한 로드맵 서비스
- **[Weave](https://github.com/kang1027/Weave)** — 한국·미국·일본 주식과 가상자산을 관리하는 macOS 메뉴바 포트폴리오 앱
- **[StayTab](https://github.com/kang1027/StayTab)** — 종료한 앱도 Command-Tab의 같은 자리에 고정하는 macOS 앱 전환기

각 제품의 자세한 내용은 Projects 항목에서 확인할 수 있습니다.
