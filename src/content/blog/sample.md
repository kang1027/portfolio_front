## 텍스트 스타일

**굵게**, *기울임*, ~~취소선~~, ==형광펜 하이라이트==, 그리고 <u>밑줄</u>까지 한 줄에 모았습니다.<br>
이 줄은 `<br>` 태그로 줄바꿈한 두 번째 줄입니다.

## 코드

인라인 코드는 `const answer = 42` 처럼 씁니다. 블록은 언어 표기와 함께:

```ts
type Post = {
  title: string;
  publish: boolean;
};

const greet = (name: string): string => `안녕하세요, ${name}님`;
```

## 인용과 각주

> 인용문은 이렇게 표시됩니다.
> 줄바꿈도 포함할 수 있습니다.

각주도 지원합니다[^1]. 두 번째 각주는 문장 끝에[^2].

[^1]: 첫 번째 각주 내용입니다. 글 맨 아래에 모입니다.
[^2]: 두 번째 각주 내용입니다.

## 수식 (KaTeX)

인라인 수식 $E = mc^2$ 그리고 블록 수식:

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i
$$

## 콜아웃 전 타입

> [!note] 메모
> 먹/백 잉크 + 번짐 텍스처. 안에서 **굵게**, `코드`, [링크](https://kang1027.com)도 됩니다.

> [!quote] 인용
> 먹/백 잉크 + 산수 안개 텍스처.

> [!example] 예시
> 먹/백 잉크 + 번짐.

> [!abstract] 요약
> 먹/백 잉크 + 번짐.

> [!tip] 팁
> 청 잉크 + 유체 흐름 텍스처.

> [!info] 정보
> 청 잉크 + 유체 흐름.

> [!todo] 할 일
> 청 잉크 + 유체 흐름.

> [!warning] 주의
> 황토 잉크 + 거친 붓터치 텍스처.

> [!danger] 위험
> 인주 잉크 + 튄 자국 텍스처.

> [!question] 질문
> 인주 잉크 + 튄 자국.

> [!success] 완료
> 송록 잉크 + 잔잔한 결 텍스처.

> [!custom] 모르는 타입
> note 스타일로 폴백됩니다.
